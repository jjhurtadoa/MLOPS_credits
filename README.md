# MLOPS Credits - Proyecto de ejemplo\n\nPlantilla mínima para la fase de Preparación y Entrenamiento (Boston Housing - open CSV).\n\nEstructura: `data/`, `src/`, `notebooks/`, `models/`, `mlruns/`, `Dockerfile.train`.\n\nComandos básicos (Windows PowerShell):\n- Crear entorno: `python -m venv .venv; .\\.venv\\Scripts\\Activate.ps1`\n- Instalar: `pip install -r requirements.txt`\n- Preparar datos: `python src/data.py --prepare --input data/raw/boston.csv --output data/processed/processed.csv`\n- Entrenar: `python src/train.py --data data/processed/processed.csv --output models/model.joblib`\n- Entrenar en Docker: `docker build -f Dockerfile.train -t mlops-train .; docker run --rm -v ${PWD}:/workspace mlops-train`\n\nSigue las convenciones DVC/MLflow para versionado y experimentos localmente.
